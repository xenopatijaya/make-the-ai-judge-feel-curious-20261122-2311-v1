[make-the-ai-judge-feel-curious-20261122-2311](https://make.fun/c/make-the-ai-judge-feel-curious-20261122-2311):
one unasked question, carried like a key to a door never seen.

`main.py` (Python 3.13, stdlib only) writes the 271-code-point text to
`/output/entry.txt` atomically, with a 1–280 code-point guard.

Run it:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
